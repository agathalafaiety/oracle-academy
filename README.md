# Oracle Academy

Repositório de estudos e exercícios desenvolvidos durante o curso **Fundamentos de Java**, da Oracle em parceria com a Gerando Falcões.

## Conteúdos

- Variáveis e tipos de dados
- Operadores e estruturas condicionais
- Laços de repetição
- Métodos e classes
- Entrada de dados com `Scanner`
- Tratamento de exceções
- Exercícios práticos, como calculadora, tabuada, despesas e cálculo de IMC

## Tecnologias

- Java
- Programação orientada a objetos

## Como executar

Tenha o JDK instalado. Depois, clone o repositório:

```bash
git clone https://github.com/agathalafaiety/oracle-academy.git
cd oracle-academy
```

Compile e execute a classe desejada. Exemplo:

```bash
javac -d out src/desafios/OlaMundo.java
java -cp out desafio.OlaMundo
```
